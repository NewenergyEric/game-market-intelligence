# GitHub 同类参考与本仓库取舍

本轮检索到的公开项目用于比较说明方式和验证习惯，不作为本项目代码依赖：

- [gamedev-ai-agents](https://github.com/ilezhnin/gamedev-ai-agents)：把设计契约、阶段计划、执行和 QA 分开；本岗位吸收“研究结论先形成证据契约，再交项目经理”的接口。
- [open-game-skills](https://github.com/jammyfu/open-game-skills)：使用 dispatcher 和 engine-neutral 路由；本岗位保留平台/地区/对象路由，但不猜测数据访问权限。
- [FunPlay Skill](https://github.com/FunplayAI/funplay-skill)：每个 Skill 都列出验证面；本仓库为每个研究命令保留测试和限制说明。
- [OpenGame](https://github.com/0xinnovator/opengame)：展示了从自然语言到阶段性游戏流程的文档方式；本岗位只负责研究证据，不承担生成游戏。

当前取舍：市场目录可以指导人工或后续连接器选源，但“收录”与“已登录、已付费、已自动采集”严格分开。
