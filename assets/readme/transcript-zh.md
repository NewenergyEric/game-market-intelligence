# 游戏市场研究总监 · 24s

三款真实产品 · 六个比较维度

## 1. 不只看品类， 还要看生意。

先明确目标玩家、地区与团队条件。

## 2. 同一张底稿， 换六个视角。

类型、IP、地区、语言、付费与产能，逐项核对。

## 3. 有语言支持， 就有市场吗？

把产品能力与当地商业表现分开判断。

## 4. 缺的证据， 变成下一轮验证。

明确谁补资料、验证什么，以及何时停止。

## 5. 团队接手时， 依据也一起走。

比较底稿、来源与未知项，交给下一轮决策。

公开资料比较；地区 CPI、LTV 与 IP 授权条款仍未知。
